# Paradise Nursery 🌱

Paradise Nursery est une application de shopping en ligne pour une boutique de plantes d'intérieur. 
L'application permet aux utilisateurs de parcourir une variété de plantes réparties en plusieurs 
catégories, de les ajouter à un panier, et de gérer les quantités avant de passer à la caisse.

## Fonctionnalités

- Page d'accueil avec présentation de l'entreprise
- Catalogue de plantes réparties en 5 catégories
- Ajout de plantes au panier
- Gestion des quantités (augmenter/diminuer)
- Suppression d'articles du panier
- Calcul automatique du total et du nombre d'articles
- Icône de panier dynamique dans la barre de navigation

## Technologies utilisées

- React
- Redux Toolkit (gestion du panier)
- Vite
- GitHub Pages (déploiement)
